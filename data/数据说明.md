### 2. 现货 $83.00 是占位价（发行价），不是成交价 —— 合并集共 **70 条**

当日 `spot_ANT_nasdaq` 中满足 `traded == true` 且 `price == 83.0` 的记录，**合并集 70 条**，分三批：

| 批次 | 文件 | src | 条数 | 时间窗 |
|---|---|---|---|---|
| 2.1 | `binance_*.jsonl`（MacBook） | yahoo | 25 | 14:37:50 – 14:40:52 |
| 2.2 | `ant_*.jsonl`（mini） | yahoo | 44 | 14:37:50 – 14:40:55 |
| 2.3 | `ant_*.jsonl`（mini） | cnbc | 1 | 16:48:26 |
| | | | **70** | |

> 更正历史：本条曾两次被记成偏小的数字 —— 先记 25 条（只数了 MacBook 文件），
> 后改成 44 条（只数了 mini 文件）。**两次都是只读了一个文件。正确数字是 70。**

**2.1 / 2.2（yahoo）**：Yahoo 在首笔成交前把发行价当行情占位返回
（`price = high = low = prevClose = 83.0`，且无成交量），而同一时刻
Nasdaq 官方接口的 `lastSalePrice` 仍为 `N/A`。

**2.3（cnbc）—— 已登记的判定规则没拦住的新花样**：
`{"price": 83.0, "quoted": 83.0, "open": 111.5, "high": 115.1, "low": 111.0,
  "prev_close": 83.0, "last_timedate": "11/18/26 EST", "src": "cnbc", "traded": true}`
CNBC 把 `prev_close`（发行价）当作 `price` 返回，但**它的 `open`/`high`/`low` 是当日真实数据**。
原判定条件「四值相等且无成交量」在此并不成立，**规则不触发**，于是 `price=83.0`
配 `traded=true` 直接入库。该条 `last_timedate` 写的是 **11/18**，前一交易日。

**处理：**
- **这 70 条一律不算成交。**
- **任何按 `traded == true` 取「首笔成交」的脚本，都会读出 $83.00 / 14:37:50，必须改。**
  正确取法：只取 `vol` 非空且 `price != 83.0` 的记录；或只信 `src=nasdaq` 且 `vol` 非空者。
- 判别占位价不要只靠「四值相等」。更可靠的组合是：`vol` 为空，或 `price == prev_close`，
  或快照自带的最后成交日期不是本交易日。
- `last_trade_ts` 单独也不可靠：16:48:18 / 16:48:21 两条 `traded=false` 的记录里，
  它写的是 `"Nov 19, 2026 11:00 AM ET"` —— 一个 11:00 的陈旧时刻。
- 本日已过首笔成交，该漏洞当日不会再触发，故**未在盘中重启采集器修补**。

**这是开盘撮合的指示价（indicative cross price）在收敛，不是买卖盘口。**

**处理：分析时须把 `bid == ask && traded == false` 的样本单独标为 `indicative_cross`，
不要混进价差、深度或盘口类计算。** 采集层尚未写出该标记，须由分析侧按此条件自行派生。

  `0x909369940f22dc1c143ac78753a33f41597138b1`
  （ethereum / arbitrum-one / binance-smart-chain / hyperevm / ink / mantle / monad）

**陷阱：`ANTX` 同时是 Nasdaq 上另一家公司 AN2 Therapeutics 的股票代码，价格在 $1–4 量级。**
以 `ANTX` 为符号向任何股票行情源取价，都可能静默返回 AN2 Therapeutics 的行情，
数字「看起来像个价格」因而不会报错，会直接污染任何 ANTx/ANT 比值。
**采 ANTx 必须以上述合约地址为主键，不得以符号字符串为主键；**
辅以断言：ANTx 价格偏离同时刻 Nasdaq ANT 超过 ±50% 即判为污染，写 `null` 并告警。
