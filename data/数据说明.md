### 3. 16:48:26 UTC：同一个占位价又从 CNBC 漏进来一条，第 2 条判定规则没拦住
一条记录：
`{"price": 83.0, "quoted": 83.0, "open": 111.5, "high": 115.1, "low": 111.0,
  "prev_close": 83.0, "last_timedate": "11/18/26 EST", "src": "cnbc", "traded": true}`

CNBC 把 `prev_close`（= 发行价 $83）当作 `price` 返回，但**它的 `high`/`low`/`open` 是当日真实数据**
（115.1 / 111.0 / 111.5）。第 2 条登记的判定条件是「四值相等且无成交量」，
此处四值并不相等，**规则不触发**，于是 `price=83.0` 配 `traded=true` 直接入库。

该条的 `last_timedate` 写的是 **11/18**（前一交易日）—— 这是比「四值相等」更可靠的判别依据。

**处理：**
- **当日 `traded=true` 且 `price==83.0` 的记录共 45 条（yahoo 44 + cnbc 1），全部不算成交。**
- **任何按 `traded == true` 取「首笔成交」的脚本都会读出 $83.00 / 14:37:50，必须改为
  先剔除 `price==83.0`，或直接只取 `src=nasdaq` 且 `vol` 非空的记录。**
- 采集器判定规则应改为：现货来路的 `price` 若其所属快照的「最后成交日期」不是本交易日，
  或 `price == prev_close` 而 `vol` 为空，则写 `null`，原值只进 `quoted`。
  （本日已过首笔成交，该漏洞当日不会再触发，故未在盘中重启采集器修补。）

### 5. ANTx（代币化凭证）尚无任何报价 —— 并附一个代码冲突陷阱
截至 2026-11-19 17:1x UTC 实测：

  唯一含 "ANT" 的是 MANTRA。Kraken 期货 `PF_ANTXUSD` 是合约，不是现货凭证。
- CoinGecko id `anthropic-xstock`（symbol `antx`，"Anthropic xStock"）条目存在，
  但 `tickers = 0`、`price = null`、`volume = null`。
- 链上合约地址（Backed 多链部署，各链同址）：
  `0x909369940f22dc1c143ac78753a33f41597138b1`
  （ethereum / arbitrum-one / binance-smart-chain / hyperevm / ink / mantle / monad）

**陷阱：`ANTX` 同时是 Nasdaq 上另一家公司 AN2 Therapeutics 的股票代码，价格在 $1–4 量级。**
以 `ANTX` 为符号向任何股票行情源取价，都可能静默返回 AN2 Therapeutics 的行情，
数字「看起来像个价格」因而不会报错，会直接污染任何 ANTx/ANT 比值。
**采 ANTx 必须以上述合约地址为主键，不得以符号字符串为主键；**
辅以断言：ANTx 价格偏离同时刻 Nasdaq ANT 超过 ±50% 即判为污染，写 `null` 并告警。
